# Original Java Reference Implementation

This directory preserves the original Java implementation of EGAGP associated
with the 2017 publication:

**EGAGP: An Enhanced Genetic Algorithm for Producing Efficient Graph Partitions**

The source files in this directory are retained unchanged from the historical
implementation for provenance, reproducibility, and comparison with the modern
Python implementation maintained in `src/egagp/`.

The legacy implementation may contain historical implementation quirks or
limitations. Changes and corrections made in the modern implementation are
documented separately.
